# 🏥 Doctor Appointment Booking System (MERN Stack)

A full-stack web application that allows patients to book and manage doctor appointments online. Built using the MERN stack with secure authentication and role-based access.

---

## 🚀 Live Demo
👉 https://doctor-appointment-system-qhf1-13m6u84jz.vercel.app/

---

## 📂 GitHub Repository
👉 https://github.com/panasasatyassai/doctor-appointment-system

---

## ✨ Features

- 🔐 User Authentication & Authorization (JWT)
- 👨‍⚕️ Role-Based Access (Admin / Doctor / Patient)
- 📅 Book, cancel, and manage appointments
- 🩺 Doctor listing and availability management
- 🔄 Real-time appointment status updates
- 🌐 RESTful API architecture

---

## 🛠️ Tech Stack

### Frontend
- React.js

- HTML5, CSS3

### Backend
- Node.js
- Express.js
- MongoDB

### Other Tools
- JWT Authentication

## ⚙️ Installation & Setup

### 1️⃣ Clone the repository
```bash
git clone https://github.com/panasasatyassai/doctor-appointment-system.git
cd doctor-appointment-system
```

### 2️⃣ Setup Backend
```bash
cd backend
npm install
npm start
```

### 3️⃣ Setup Frontend
```bash
cd frontend
npm install
npm start
```

---

## 🔑 Environment Variables

Create a `.env` file in backend folder and add:

```
MONGO_URI=your_mongodb_connection
JWT_SECRET=your_secret_key
```
